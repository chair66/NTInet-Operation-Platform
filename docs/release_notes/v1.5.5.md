# NOP v1.5.5 — Enterprise Provider Framework

## Added

- NOP product identity and v1.5.5 release foundation.
- Shared `ProviderClient` with timeout, retries, correlation IDs, structured logging, and common errors.
- Thread-safe provider registry and configuration reports.
- BrandVNO/OXIO provider using Basic Authentication.
- Live SIM inventory refresh with local cache fallback.
- Provider Health administration page with read-only live checks.
- Architecture, provider-framework, and coding-standard documentation.

## Operational behavior

Opening SIM Management refreshes inventory when the user has SIM-management permission. **Refresh Inventory** reruns the same operation. If BrandVNO is unavailable, NOP displays cached inventory and records the failure without exposing credentials.

## Upgrade

Extract this package over the project root, preserve `.env` and the production database, restart the application, and visit `/admin/providers` followed by `/mobile/sims`.
