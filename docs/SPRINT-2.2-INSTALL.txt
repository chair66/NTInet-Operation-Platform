NOP v1.6.0 - Sprint 2.2: Domain Page Cleanup

PURPOSE
Replaces the DigiCloud Domains page with a compact directory-style layout.
No routes, Python code, permissions, or database tables are changed.

FILES
app\templates\digicloud\domains.html
app\static\style.css

INSTALL
1. Stop Uvicorn with Ctrl+C.
2. Extract this ZIP to a temporary folder.
3. Copy the included app folder into the root of ntinet-operations-platform.
4. Allow Windows to merge folders and replace the two matching files.
5. Restart with:
   python -m uvicorn app.main:app --reload
6. Open /digicloud/domains and press Ctrl+F5.

NOTES
- No database backup is required for this UI-only patch.
- Delete remains protected: the red action opens the domain detail page where the exact domain name must be entered.
