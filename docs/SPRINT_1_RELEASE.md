# DigiCloud Platform v3.0 — Sprint 1 Foundation

## Added

- Provider abstraction and registry
- Initial Bandwidth provider adapter
- Module registry
- Generic provider resource and organization assignment models
- Provisioning job, task, and template models
- Organization-scoped ResourceService
- ProvisioningEngine foundation
- Provisioning overview, jobs, and templates pages
- New provisioning and provider permissions
- DigiCloud Operations Platform branding
- Architecture and sprint documentation

## Compatibility

Existing Bandwidth routers and service calls were intentionally left in place. This release adds the platform layer alongside the existing implementation so current number, porting, CSR, authentication, and MFA workflows are not needlessly disrupted.

## Version

`3.0.0-sprint1`
